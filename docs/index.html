Help & Clarifications

Frequently Asked Questions

Got questions about profile isolation, disk footprints, or quotas? We have answers.

How does Multigravity differ from simply opening a new Antigravity window?
Standard windows in Antigravity share the exact same user data directory, Google authentication token, and AI quota pool. Multigravity isolates the underlying --user-data-dir and redirects environment variables so you can log into completely different Google accounts simultaneously with independent rate limits and quotas.
Will my Google account login or OAuth tokens leak between profiles?
No. Multigravity enforces strict isolation invariants. Authentication tokens (such as jetski-standalone-oauth-token and installation IDs) reside outside shared symlink directories and are never synchronized, exported, or linked across profiles.
How does an Auth-Only profile achieve ~2 MB without breaking extensions?
Instead of duplicating hundreds of megabytes of extensions and themes from your host machine, an Auth-Only profile creates lightweight symbolic links (or NTFS Directory Junctions on Windows) pointing to your existing host extension folder and editor keybindings. Only the session state and auth tokens are stored locally in the profile.
How does headless quota priming work without opening the graphical IDE?
The Antigravity Language Server can run headlessly with an ephemeral port. Multigravity launches this binary in background mode, queries the gRPC/HTTPS telemetry endpoint, and sends a minimal, randomized conversational ping (<5 tokens) using the lightest available model (gemini-3.6-flash-low) to start the 7-day countdown cycle immediately after a quota refresh.
Can I use Multigravity on Windows without WSL?
Yes! Multigravity is written in native Go and features full Windows support. It runs directly inside Windows PowerShell, uses NTFS Junctions instead of symlinks to avoid requiring Administrator privileges, and integrates with the Windows Start Menu via native .lnk shortcuts and embedded .ico icons.
How do I completely uninstall Multigravity and remove all profiles?
Run ./uninstall.sh on Linux/macOS or ./uninstall.ps1 on Windows. The script cleans up binary links in ~/.local/bin, desktop shortcuts, background cron/systemd jobs, and prompts whether you want to preserve or remove profile directories in ~/AntigravityProfiles.
