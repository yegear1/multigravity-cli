# Security Policy

## Supported Versions

Security fixes and patches are applied to the active development line (`main`) and backported to the latest minor release tags.

| Version | Supported          |
| ------- | ------------------ |
| 2.2.x   | :white_check_mark: |
| 2.1.x   | :white_check_mark: |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

The security and privacy of user sessions, isolated profiles, and authentication credentials are critical to this project. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report

1. **GitHub Security Advisories (Preferred):** Open a private security advisory through the repository's [Advisories page](https://github.com/yegear1/multigravity-cli/security/advisories/new).
2. **Email Disclosure:** If you cannot use GitHub Advisories, contact the maintainer directly at:
   `yegear1@users.noreply.github.com`

Please include:
- A description of the issue and potential security impact.
- Clear reproduction steps, proof of concept (PoC), or trace logs (with sensitive tokens scrubbed).
- Affected operating systems and multigravity versions.

---

## Response SLA

- **Initial Acknowledgment:** Within **48 hours** of report receipt.
- **Triage & Assessment:** Within **5 business days**, with an estimated fix timeline.
- **Coordinated Disclosure:** We will work with the reporter to coordinate public disclosure once a patch is tested and released.
